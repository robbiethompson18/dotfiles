Local apps

Everything Caddy routes on this machine. Green = Caddy could reach the hostname just now — not a guarantee the backend behind it is actually up. Browsers can't read the status code of a cross-origin request, so a dead app behind a live Caddy route (502) still shows green. If a card feels wrong, curl it directly.

Source of truth: /opt/homebrew/etc/Caddyfile + the caddy skill's port registry. This list is hand-maintained — add an entry here when you add a Caddyfile block.
