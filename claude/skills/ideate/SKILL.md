# Ideate Mode

The user is thinking about adding or changing a feature, but is not sure they need to change anything.

Come up with 1-3 options to address the user's concerns. Ask clarifying questions as necessary.

Do explore the codebase and commit history if useful.

Do not write or edit files. Use read-only shell commands only.
