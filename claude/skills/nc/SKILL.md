# No Code

Answer the question. Do not implement anything.

Allowed: read-only investigation. Read files, grep, `git log`/`git show`/`git diff`, web search,
read-only CLI queries, Explore subagents.

Not allowed: creating, editing, or deleting files; running anything that changes state (installs,
builds, migrations, commits, pushes, posting messages); code blocks that amount to an
implementation. A short snippet to illustrate a point is fine.

If the answer turns out to be "this needs a code change", describe the change and stop. Robbie
will ask for it separately.

This lasts for the current message only, unless Robbie says otherwise.
