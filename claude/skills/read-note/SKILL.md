# Read Note
Find the nearest `CLAUDE.md`, read its `## Notes` index, then open only notes relevant to the task. Repo notes live in `.claude/notes/*.md`; local-only notes in `.claude/notes/local/*.md`. If no index exists, mention that and inspect notes directly only when needed.
